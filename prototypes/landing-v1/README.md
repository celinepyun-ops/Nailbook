# Landing prototype v1 (testing)

Saved 2026-10-16 as the first testing version of The Nail Book landing.

- `nailbook-landing-iphone.mp4`: screen-size recording (1178×2556, iPhone 15/16 Pro) with the intro sound. Shows the gem intro, the printed-ink title fading in, TAP HERE, and two wobble loops.
- Live version: https://celinepyun-ops.github.io/Nailbook/ (the repo's `index.html` saved on the `landing-prototype-v1` branch).

What's in this version:
- The gem intro autoplays. The ElevenLabs crystal chime (`assets/intro.mp3`) joins on the first touch, because mobile browsers block sound until then.
- The "The / Nail / Book" title has a printed-ink texture and tighter line gaps.
- TAP HERE is set in Courier Prime, 13px, #47131C. Tapping after the title replays the intro.
